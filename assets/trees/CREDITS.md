# Tree credits

`trees.webp` is rendered (by `tools/bake/tree_sprites.py`, in Blender) from these Poly Haven
models, all public domain (CC0 1.0):

- [Island Tree 02](https://polyhaven.com/a/island_tree_02)
- [Tree Small 02](https://polyhaven.com/a/tree_small_02)
- [Fir Sapling Medium](https://polyhaven.com/a/fir_sapling_medium) (one sapling from the set)

Each tree is drawn from two sides and used as crossed billboards in the game.
